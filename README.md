# USTB Grade Enhancer

北京科技大学"本研一体化教务管理系统"（byyt.ustb.edu.cn）的油猴脚本，适配 **2026 年 10 月改版后**的新接口。

## 功能

- **实时加权计算**：在成绩页面自动计算加权均分（学分加权），自动排除辅修、形势与政策、专业拓展等不计入学分的课程（排除清单可自行维护）
- **单课课程排名**：显示每门课的"排名/总人数"（数据来自教务接口，约半数课程有排名）
- **单人查询**：输入任意学号，页面成绩表格切换为该学生的全部成绩（含排名）
- **批量查询**：导入含"学号/姓名"两列的 Excel，自动逐人查询并导出汇总+明细两个 Sheet，汇总自动按加权分排名
- **学年筛选**：支持按学年（如 `2024-2025`）筛选统计范围

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 打开 [USTB加权成绩批量查询v10.user.js](./USTB加权成绩批量查询v10.user.js) 的 GitHub Raw 页面，Tampermonkey 会自动弹出安装提示；或在 Tampermonkey 中新建脚本后粘贴全文保存
3. 打开教务系统：主页 → 快捷信息"成绩"标签 → 查看更多（或 全部功能 → 学生学习进度查询），右下角出现脚本面板

> Edge 用户注意：`edge://extensions` → Tampermonkey → 详细信息 → 开启"允许用户脚本"。

## 使用说明

- **查询单人**：面板输入学号 → "查询单人加权"。当前停留在成绩页时，页面表格会切换为该学生的成绩并在备注列显示排名
- **批量**：准备 Excel（第一行含"学号""姓名"列），点"批量查询"导入；每人约 1-2 秒，完成后自动下载 Excel
- **统计口径**：默认全部已出成绩课程，面板可填学年筛选；排除规则在脚本头部 `KCDM_EXCLUDE` / `KCLBDM_EXCLUDE` 处可自行修改

## 已知限制

- 部分课程（约半数）教务接口未提供排名数据
- 批量查询走本人会话，请仅用于班级学习服务，导出数据注意保管
- 仅供学习交流使用，请勿用于任何违规用途；接口如再改版请提 Issue
